## 1. エグゼクティブサマリー & 設計思想

本仕様書は、GitHub Pages（プロジェクトサイト `https://tadaodev.github.io/sales_lp/`）配下のサンプル第2弾として公開される「カジュアルイタリアン・薪窯ピッツァ＆手打ちパスタ専門店向け高成約率LP（`samples/italian/index.html`）」の実装に必要な、**新PASONAの法則（Problem・Affinity・Solution・Offer・Narrowing Down・Action）に基づくセールスコピーライティング、料理画像アセットの最適配置、14日間ランチ/ディナー席予約カレンダー、モーダル連動、LINE誘導、FAQおよびUI/UXコンポーネント仕様**を網羅的に定義した完全設計書である。

本設計は、プロジェクト標準スキル（`lp-pasona`、`ui-ux-pro-max`）のフレームワークに完全準拠し、**暖色系（テラコッタ・ワインレッド・オリーブグリーン・温かみある木目調）のモダンUI**によって食欲とシズル感を極大化させつつ、来店前の不安（価格感・席の混雑・味のクオリティ・利用シーン）を完全に払拭し、スムーズなWeb席予約およびLINE予約へと誘導する。

## 8. エッジケース & 挙動仕様（Edge Cases）

| # | 対象機能 | 想定インプット・状況 | 期待・設計される挙動 |
| :-: | :--- | :--- | :--- |
| **1** | 席予約カレンダー | 定休日（毎週火曜日）のセルがクリックされた場合 | セルは無効化スタイル（グレー背景・カーソル禁止）となり、「休」バッジが表示され、モーダルは開かない。 |
| **2** | 席予約カレンダー | 満席（✕）のセルがクリックされた場合 | 満席アラートメッセージ「申し訳ございません。この時間帯は満席です。別の日時をお選びいただくか、キャンセル待ちはお電話（03-5678-9012）にて承ります」が表示される。 |
| **3** | Web予約フォーム | 必須項目（メールアドレス・電話番号・人数）の空欄または不正形式 | HTML5標準バリデーションに加え、カスタムインラインエラーメッセージが表示され、送信処理を未然に防止する。 |
| **4** | モバイル追従バー | 最上部ヒーロー閲覧時、または予約カレンダー表示中 | ヒーロー内では自然に非表示（透過）、予約カレンダー/フォームセクション到達時はボタンの重複を防ぐため自動的にフェードアウトする。 |
| **5** | 極小画面（375px） | iPhone SE等でのプライシングテーブルやカレンダー閲覧 | コース表は縦スタックに自然に切り替わり、カレンダーは横スクロールコンテナ（`-webkit-overflow-scrolling: touch`）で快適にスクロール可能。 |
| **6** | サーバーレス連携 | GAS Webhook URLが空（未設定）または通信タイムアウト | 動的シミュレーションエンジン（`simulationSeedSalt`）により、日付に基づく決定論的な空き枠判定（◯・△・✕）と予約受付完了画面（予約番号発行、.icsダウンロード）が破綻なく完結動作する。 |
| **7** | アクセシビリティ | キーボード操作（Tab/Enter/Space）およびスクリーンリーダー | FAQアコーディオン、モーダル開閉、カレンダーセルに適切な `role="button"`、`aria-expanded`、`tabindex="0"` が付与され、視覚なしで操作可能。 |
| **8** | 静的相対パス | GitHub Pagesのサブディレクトリ配下（`/sales_lp/samples/italian/`）での実行 | 全CSS、画像、JS、戻りリンクが完全な相対パス（`../../` または `./`）で参照され、404エラーが一切発生しない。 |

# 🚀 エステサロンLP専用 Google連携バックエンド導入手順書 (3分設定ガイド)

このドキュメントは、エステサロンLP（ランディングページ）と**「Googleカレンダー」**および**「Googleスプレッドシート（予約顧客台帳）」**を完全無料で自動連動させるためのセットアップ手順書です。

ITやプログラミングの知識がないサロンオーナー様でも、**画面の指示通りにコピペするだけで【最短3分】で導入が完了**します。

---

## 🌟 本システムの特徴とメリット

| 特徴 | 内容 |
|---|---|
| **💰 サーバー費用 0円** | Google公式のクラウドインフラ（Google Apps Script）を利用するため、月額費用・初期費用は永久に無料です。 |
| **📅 Googleカレンダー完全自動連動** | 普段スマホでお使いのGoogleカレンダーにプライベート予定を入れるだけで、LP側のカレンダーが自動で「✕（満席）」に切り替わります。 |
| **📋 予約台帳の自動生成** | LPから予約が入ると、Googleスプレッドシートに顧客情報・コース・日時が即座に自動記録されます。 |
| **✉️ 上質な自動返信メール** | お客様宛の丁寧な予約確認メールと、オーナー様宛の予約通知メールが即座に自動送信されます。 |
| **🛡️ 堅牢なフォールバック機能** | 万が一GASの設定前や通信不通時でも、LP画面がエラーで止まることなくシミュレーション稼働します。 |

## ⏱️ 3分で完了！簡単4ステップ・セットアップ

```
【手順の全体像】
[Step 1] Googleスプレッドシート作成 ──> [Step 2] Code.gs を貼り付け
                                                  │
[Step 4] LP側の config.js にURL貼り付け <── [Step 3] ウェブアプリとしてデプロイ
```

---

### Step 1. Googleスプレッドシートを作成してスクリプトエディタを開く

1. お手持ちのブラウザ（Google Chrome推奨）で [Google ドライブ](https://drive.google.com/) を開きます。
2. 画面左上の **「＋ 新規」** ＞ **「Google スプレッドシート」** ＞ **「空白のスプレッドシート」** をクリックします。
3. スプレッドシートのタイトル（左上の「無題のスプレッドシート」）を **`エステサロン予約管理台帳`** に変更します。
4. 上部メニューバーの **「拡張機能」** をクリックし、**「Apps Script」** を選択します。
   - 新しいタブで Apps Script エディタ（スクリプト編集画面）が開きます。

---

### Step 2. `Code.gs` のコードを貼り付けてサロン情報を設定する

1. Apps Script エディタに最初から表示されている `function myFunction() { ... }` をすべて削除して空にします。
2. 本リポジトリの **`gas/Code.gs`** のコードをすべてコピーし、エディタに貼り付けます。
3. コード最上部の `CONFIG` エリア（10〜40行目付近）をお客様のサロン情報に合わせて編集します。

```javascript
// ==========================================
// 1. サロン共通設定 (Salon Configuration)
// ==========================================
var CONFIG = {
  // サロン基本情報（メール文面やカレンダーに反映されます）
  SALON_NAME: 'Salon de Étoile（サロン ド エトワール）',
  SALON_PHONE: '03-5555-0192',
  SALON_EMAIL: 'info@example-etoile.jp', // サロン通知を受け取るメールアドレス
  SALON_ADDRESS: '東京都中央区銀座6-10-1 GINZA SIX 8F',
  SALON_ACCESS: '東京メトロ銀座駅 A3出口 徒歩2分 / 東銀座駅 A1出口 徒歩3分',
  
  // Googleカレンダー設定 ('primary' のままでOKです)
  CALENDAR_ID: 'primary',
  
  // 定休日設定 (0: 日, 1: 月, 2: 火, 3: 水, 4: 木, 5: 金, 6: 土)
  CLOSED_DAYS: [2], // 例: 毎週火曜日定休
  
  // 提供時間枠 (1日4枠)
  TIME_SLOTS: ['10:00', '13:00', '16:00', '18:30'],
  
  // ...
};
```

4. エディタ上部の **「フロッピーディスクのアイコン（保存）」** をクリックして保存します。

---

### Step 3. 「ウェブアプリ」としてデプロイする（重要）

1. 画面右上の青いボタン **「デプロイ」** ＞ **「新しいデプロイ」** をクリックします。
2. 左側の歯車マーク（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
3. 以下の通り設定項目を入力・選択します：
   - **説明**: `v1.0.0`（任意でOK）
   - **次のユーザーとして実行**: **`自分（オーナー様のメールアドレス）`** を選択
   - **アクセスできるユーザー**: **`全員`** を選択（※必ず「全員」にしてください。ログイン不要でLPからアクセス可能にするためです）
4. 右下の **「デプロイ」** ボタンをクリックします。

#### ⚠️ 初回デプロイ時の「Googleアクセス承認」画面の進め方
Googleのセキュリティ確認画面が表示された場合は、以下の手順で進めてください（ご自身の作成したスクリプトへのアクセス許可ですので完全安全です）：

1. **「アクセスを承認」** ボタンをクリック ＞ ご自身のGoogleアカウントを選択します。
2. 「Google hasn't verified this app（このアプリは Google で確認されていません）」という警告画面が出ます。
3. 画面左下の小さな文字 **「Advanced（詳細）」** をクリックします。
4. 下部に現れる **「Go to ... (unsafe) / 〇〇（安全ではないページ）に移動」** をクリックします。
5. 必要な権限一覧（カレンダー、スプレッドシート、メール送信）が表示されますので、右下の **「Allow（許可）」** をクリックします。

---

### Step 4. 発行されたWebアプリURLを `config.js` に貼り付ける

1. デプロイが完了すると、**「ウェブアプリ」** のURL（例: `https://script.google.com/macros/s/AKfycbx.../exec`）が表示されます。
2. **「コピー」** ボタンを押してURLをクリップボードにコピーします。
3. LP側の設定ファイル **`samples/aesthetic/js/config.js`** を開き、`gasWebhookUrl` に貼り付けます：

```javascript
// samples/aesthetic/js/config.js
var SALON_CONFIG = {
  // ...
  gasWebhookUrl: 'https://script.google.com/macros/s/AKfycbx.../exec', // ← ここに貼り付け！
  // ...
};
```

4. ファイルを保存してブラウザでLPを再読み込みすれば、**Googleカレンダー・スプレッドシートとのリアルタイム完全連動が開始**されます！🎉

## ❓ よくある質問とトラブルシューティング (FAQ)

### Q1. LPのカレンダーが「休」や「✕」ばかりになってしまう
- **原因 1**: Googleカレンダーの該当時間帯に、終日予定や別件の予定が入っている可能性があります。
- **原因 2**: `CONFIG.CLOSED_DAYS` の定休日設定（例: 火曜定休など）と照合してください。
- **原因 3**: 当日の過去の時間は、自動的に「受付終了（✕）」と判定されます。

### Q2. 予約ボタンを押したときに「通信エラー」が表示される
- **確認点 1**: Step 3のデプロイ時、「アクセスできるユーザー」を **`全員`** に設定しているか確認してください（「自分のみ」になっているとアクセス拒否されます）。
- **確認点 2**: `Code.gs` を修正した場合は、必ず「デプロイ」＞「デプロイの管理」＞鉛筆マーク＞「バージョン: 新しいバージョン」を選択して再デプロイしてください。

### Q3. メール送信元のメールアドレスはどこになりますか？
- スクリプトをデプロイしたオーナー様のGoogleアカウント（Gmail）のアドレスから送信されます。サロン独自のドメインメールを使用したい場合は、Google Workspaceのご利用を推奨いたします。

### Q4. GASを設定しない状態でもLPは動きますか？
- はい。`gasWebhookUrl` が空文字のままでも、LP内蔵の**「決定論的シミュレーションエンジン（動的フォールバック）」**が自動稼働し、リアルな空き状況表示や予約完了（サンクス）画面、カレンダー追加（.ics）、公式LINE連携まで破綻なくデモ動作します。

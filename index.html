DESIGN PHILOSOPHY

成約を生み出す3つの設計思想

新PASONAの法則 (New PASONA)

Problem（問題提起）→ Affinity（親近感・共感）→ Solution（解決策）→ Offer（提案・価格）→ Narrowing Down（限定性）→ Action（行動喚起）の科学的心理導線を全ページに実装。

ゼロ外部依存・高耐久設計

ビルドツールや外部重厚ライブラリに一切依存せず、Pure Vanilla HTML5 / CSS3 / Vanilla JSで構築。CDN障害時やオフライン環境でも100%崩れない耐障害性を保証。

GitHub Pages 完全対応

GitHub Pagesのサブディレクトリ配信（username.github.io/repo/）に完全対応した相対パス設計（./, ../../）。404エラーを徹底排除。
